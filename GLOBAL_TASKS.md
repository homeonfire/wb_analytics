# Глобальный план задач (Vue 3 + Inertia + Tailwind)

Этот файл отслеживает глобальный прогресс по переводу и доработке функционала Wildberries Analytics.

## ✅ Реализовано
- **UI/UX Дизайн**: Внедрена Glassmorphism тема, переписаны глобальные стили (`app.css`, `tailwind.config.js`).
- **Авторизация**: Переписаны шаблоны и форма входа под общий стиль. Отключена неиспользуемая стартовая страница Laravel.
- **Главное меню (Sidebar)**: Меню разбито на логические блоки с красивыми иконками (`lucide-vue-next`).
- **Каталог товаров (`Products`)**:
  - Карточный список с умным поиском и сортировкой.
  - Детальная карточка товара.
  - **Калькулятор юнит-экономики**: динамический расчет прибыли, маржи, ROI (с учетом комиссий и налогов).
- **Магазины / Кабинеты (`Stores`)**:
  - Страница управления магазинами.
  - Добавление API ключей (Контент, Статистика, Реклама).
  - Удаление магазинов.
  - Автоматическая привязка к текущему пользователю.
- **Менеджеры (`Managers`)**:
  - Создание пользователей прямо из интерфейса (без Filament).
  - Модальное окно привязки товаров (с удобным поиском по баркодам и массовым выбором).
- **Заказы и Продажи (`Orders/Sales`)**: Единая страница с вкладками для сырых заказов и выкупов, фильтрация, отображение реальной выручки.

## ⏳ В планах
- **Аналитика воронки (`Analytics`)**: Перенос графиков воронки (Open -> Cart -> Order -> Buyout).
- **Реклама (`Adverts`)**: Управление кампаниями и внешней рекламой.
- **Логистика (`Logistics/Stocks`)**: Отображение FBO остатков по складам.
- **Дашборд (`Dashboard`)**: Главный экран с виджетами общей выручки и графиками продаж.
- **Аналитика ABC (`ABC Analysis`)**: Вывод категорий A/B/C для товаров.
